# Literature sources

`sources.json` and `download_manifest.json` list the course reading sources and preparation records. Paper PDFs are excluded from Git. To download local copies, run `python scripts/download_literature.py` from the repository root. Check each paper's original source and licensing before redistribution.

The ten recommended papers cover MVTec AD, PaDiM, PatchCore, DRAEM, CutPaste, DINOv2, AnomalyCLIP, AnomalyDINO, EfficientAD and MVTec AD 2. Source collection is not a claim that the final related-work section has been written or every paper has been critically reviewed. Cite original datasets, pretrained models, repositories and borrowed components in the final report.
